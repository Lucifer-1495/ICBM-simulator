A cinematic, interactive 3D simulation of a global missile defense and strike terminal. This project blends a "retro-cyberpunk" terminal aesthetic with a modern Three.js 3D globe visualization.

🚀 Features
1.3D Interactive Globe: Built with Three.js, featuring realistic Earth textures, orbital controls (zoom/rotate), and dynamic lighting.<br>
2.Multi-Stage Authentication: A scripted "Boot Sequence" followed by a mock biometric face scan and passcode verification system.<br>
3.Tactical Radar HUD: A custom HTML5 Canvas radar that sweeps for targets and tracks missile progress in real-time.
4.Dynamic Missile Physics: Missiles feature particle-based exhaust trails and calculated trajectories from silos to target coordinates.
5.Nuclear Yield Simulation: Different warhead selections (W88, B83, RS-28) trigger varying explosion scales, complete with screen-shake effects, point-light flashes, and 3D particle expansion.
6.Immersive Audio: Integrated siren alarms, launch "whooshes," and impact sound effects for a complete sensory experience.

🛠️ Tech Stack
1.Frontend: HTML5, CSS3 (Flexbox, Animations)
2.3D Graphics: Three.js
3.2D Graphics: HTML5 Canvas API
4.Audio: JavaScript Web Audio handling
5.Libraries: OrbitControls.js for camera manipulation

🕹️ Operational Flow
1.System Boot: Wait for the secure protocols to initialize.
2.Authentication: Complete the "Face Scan" and enter the decryption keys (Lucifer#1495# / LuffyBankai).
3.Targeting: Input coordinates to lock onto a specific geographic region.
Configuration: Select your launch silo (Alaska, Nevada, India, Russia, or China), missile type, and warhead yield.

Execution: Initiate the countdown and watch the 3D globe and radar for impact verification.
